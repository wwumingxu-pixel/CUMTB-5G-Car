# CUMTB-5G-Car

中国矿业大学（北京）5G 智能车相关代码与测试资料。

本仓库主要记录 5G 远程驾驶无人车项目中的视觉识别、巡线、硬件控制和测试代码，方便后续调试、复现与交流。

## 目录说明

- **[wmx](./wmx/)**：当前使用和持续整理的主代码目录。各 `.cpp` 文件名已经标明主要用途，包括巡线、锥桶识别、斑马线检测、挡板检测、红绿灯识别、舵机/马达控制、语音播放以及图像传输等。
- **[old](./old/)**：项目开发过程中的历史版本和旧代码，仅用于参考、对比和追溯，不保证与当前硬件及环境完全兼容。
- **[wmxd](./wmxd/)**：Windows 下的视觉算法测试工具。Release 中提供 Canny 巡线测试的可执行程序及使用说明。

## Windows 测试工具

Release 中提供三个无需单独配置 Python 环境的 Windows 测试工具：

- `CannyFillScanTester.exe`：Canny 边缘检测结合填充/扫描方式的巡线测试。
- `CannyTester.exe`：测试图片 Canny 边缘检测与巡线效果验证。
- `CannyVideoTester.exe`：读取视频或摄像头画面进行连续帧 Canny 巡线测试。

详细使用方法见 [`wmxd/README.md`](./wmxd/README.md)。这些工具仅用于视觉算法验证，不控制树莓派 GPIO、电机或舵机。


- **摄像头采集链路优化**：需要视觉处理或图传的程序不再直接请求低分辨率；改为先采集 `1920x1080`，再根据程序用途缩放到 `320x180` 或 `640x360`，以保留更完整的摄像头视野并降低后续处理负担。
- **加入键控驾驶**：新增 `keyboard_http_control.cpp`，支持网页按钮、W/A/S/D 和方向键控制前进、后退、转向；可以分别设置前进/后退 PWM，松开按键、网页失焦或心跳超时会自动停车。
- **电机测试改进**：`mada.cpp` 改为交互式 PWM 测试，可直接输入 PWM 验证停止、前进和后退，退出时自动回到停止中位；`motor_scan.cpp` 支持配置扫描起止值、步进和停留时间。
- **视觉识别调整**：`honglvdeng.cpp` 改用“红灯持续确认 → 绿灯连续帧确认”的状态机；`banmaxian.cpp`、`dangban.cpp`、`zhuitong.cpp` 使用高分辨率采集后缩放的处理流程。
- **舵机测试调整**：`duoji.cpp` 使用 BCM GPIO12 和脉宽映射方式，缩小扫描范围以便现场标定；`pid_servo_test.cpp` 用于舵机 PID、回中角度和响应参数测试。
- **图传优化**：`tuchuan_http.cpp` 将采集、缩放、JPEG 编码与客户端发送分离，只保留最新帧，减少网络拥塞导致的延迟。

## 运行环境

部分程序面向树莓派或类似 Linux 嵌入式平台，可能依赖：

- C++ 编译器（支持 C++17）
- OpenCV
- pigpio（仅硬件控制相关程序需要）
- 摄像头、舵机、电机及相应驱动电路（仅对应硬件程序需要）

视觉测试程序通常可以使用类似下面的命令编译：

```bash
g++ wmx/xunxian.cpp -std=c++17 -o xunxian $(pkg-config --cflags --libs opencv4)
```

硬件控制程序还需要根据实际平台和接线方式链接、配置 `pigpio`。不同文件中的摄像头编号、IP 地址、GPIO 引脚和阈值参数可能需要按实际设备修改，使用前请先阅读源文件中的注释。

## 图片测试

`wmx` 中带有 `image_test` 后缀的程序用于读取图片进行离线测试。运行时通常需要将图片路径作为参数传入；具体参数格式请以对应源文件中的说明和代码为准。

## 注意事项

1. 硬件控制代码运行前请确认 GPIO 接线、电机驱动和供电安全，避免直接连接或误操作造成设备损坏。
2. 本仓库中的代码包含开发阶段测试程序和历史版本，建议优先从 `wmx` 目录开始阅读。
3. 测试图片仅用于本项目视觉算法验证。如需将本项目用于其他用途，请自行确认图片及第三方依赖的授权情况。
